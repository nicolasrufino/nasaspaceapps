Milestone M1, issue #31. This prepares the `rocks_fine.u8` layer consumed by
the existing scout feature. It adds no feature flag and changes no contract.
R5 can use the resulting world, while reporting its limited positive coverage.

## Current gate

All 25 proposals now have human decisions: 23 accepted, H02 and H13 uncertain,
none rejected. The final delivery excludes both uncertain points and uses the
default complete-review gate. No additional visual review is required for this
delivery. The H agreement is 23/23 resolved proposals, with two uncertainties

The 25 frozen H proposals are reviewed in batches; exact current decisions
and coverage are recorded in the artifacts, not inferred from model scores.
`r3_decisions.json` preserves the exact responses and hashes the frozen
`r3_candidates.json`. The default export refuses incomplete reviews; duplicate,
unknown or unsupported decisions always fail. `--reviewed-only` explicitly
permits a partial delivery: only confirmed points contribute, while
uncertain and unreviewed proposals remain excluded. Review coverage is
stated in the report. A preview is allowed but never stages a world.

## Same site, distinct image products

The target is Luca's 2048 m square Gale site, centred at 137.383 E, −4.800,
256 × 256 cells at 8 m, with north at row zero. The reference colour mosaic
is the same USGS MSL Gale HiRISE LRGB product and window used by the world
pipeline. ROSCO runs on the separate NASA/JPL/University of Arizona HiRISE
acquisition ESP_019698_1750, acquired 2010-10-09, whose Sun geometry is known.
It is the same ground, **not the same image**. See `ROSCO.md` for provenance.

The affine registration in #86 is unchanged. `r3_alignment.py` checks a
256 m texture patch around each candidate after applying that transform,
including the two candidates beyond the fitting-control extent. Both
high-pass and gradient signals must have response ≥0.2 and displacement
≤4 m; at least 75% of the patch must contain real image data. These are
diagnostic thresholds, not calibrated bounds on individual rock positions.
All 25 pass; values and source hashes are in `r3_alignment.json`.

## What the exported mask means

Only a human-accepted point with a passing local alignment check contributes
to the positive mask. The point's 8 m cell and its eight neighbours are
marked. This one-cell padding is a conservative **demo design choice**,
not a measured rock footprint, density, height or validated clearance distance.
ROSCO's unvalidated size estimates and the user's marker circles are not
used as physical boundaries. Rejected, uncertain and unreviewed points do
not contribute. A zero cell does not mean the ground is safe or surveyed.

Accepted native detections are counted per 64 m² grid cell before padding;
the report includes these counts and their density in rocks/m². They describe
the reviewed sample, not exhaustive rock abundance.

The final world mask is the union with Luca's existing DTM roughness estimate.
Those earlier hazards remain estimates; the visual review does not validate
them. No existing hazard is removed. The return-cost layer is recomputed on
the same height, classes, gravity and energy knobs, with blocked cells set
to the contract's unreachable sentinel. Any habitat overlap or unexpected
cost reduction fails the export. Optical, terrain, targets, route, other
NASA layers and scout flight paths are preserved.

## Reproduction

### PR #94 refresh

The input reference now pins Luca's `1d93099a0aeceec60219ac6c81f32e408482752e`
world (PR #94, including the EVA scenarios and final 20° world/crossing rebuild). The site, grid, height,
slope, classes, optical image and combined rock mask match the reviewed
delivery. All 23 accepted points and both excluded uncertainties are unchanged.
The exporter checks the pipeline's energy knobs and serialized terrain factors,
accepts crossing metadata, and passes the pinned `passable.u8` to the builder.
An unsupported energy model or a missing/changed crossing layer still fails closed.

This is a refresh of an already integrated mask: 1,143 input hazard cells are
retained, 180 cells belong to the reviewed clearance mask, and zero new cells
are added. The legacy `existing_dtm_cells` field counts the entire input mask,
including earlier reviewed additions; `existing_layer_scope` makes that explicit.
The re-export also restores the existing R3 unreachable sentinel on blocked
starting cells. Publish its `cost_to_go_scouted.f32` and report together.
No other world layer or metadata semantics change. Regenerate R5 afterwards.

All commands run from the repository root. Native imagery and ROSCO run
outputs are ignored local inputs, prepared using `ROSCO.md`.

```sh
python -m ml.rock_review.r3_review ml/data/gale-ESP_019698-v2 ml/runs/gale-rosco-confidence-v2 ml/runs/r3-review-new
python -m ml.rock_review.r3_alignment ml/data/gale-ESP_019698-v2 ml/data/gale-final-v1/gale_final_rgb.png ml/runs/r3-alignment-new.json
python -m ml.rock_review.r3_hazards data/worlds/gale ml/runs/r3-preview-new --preview
# Requires decisions for all 25 proposals:
python -m ml.rock_review.r3_hazards data/worlds/gale ml/runs/r3-export-new
# Future partial batches can explicitly use --reviewed-only.
python data/pipeline/check_world.py ml/runs/r3-export-new/world
```

Use a new destination each time. Review regeneration preserves H01–H06
identities and fails if their native coordinates differ. The frozen review
also records PNG hashes for H07–H25. Do not replace human decisions with
generated defaults; unresolved proposals stay excluded even in reviewed-only mode.

`r3_world_reference.json` freezes the input world metadata and binary-layer
hashes at the recorded dev commit. A later world change fails closed and
requires checking compatibility; never overwrite a teammate's new world
from an old export. For reproduction after integration, obtain that input
world from its recorded commit, then run the export into a fresh directory.

The output folder contains `rocks_verified.u8` (positive additions),
`rocks_fine.u8` (combined mask), `rocks.json` (evidence and agreement), and,
for a delivery (not a preview), `world/` (staged integration). Binary drafts stay
in ignored `ml/runs/`. To integrate, copy only the staged world's three
changed files (`rocks_fine.u8`, `cost_to_go_scouted.f32`, `world.json`) into
the real world, and publish its report as `ml/exports/rocks.json`. Re-run
world, app and CI checks before merging. The report records the exact numbers
of accepted points, added cells and retained DTM-estimate cells for each delivery.

Agreement is the accepted fraction among resolved frozen H proposals,
with uncertainty reported separately. It is not held-out accuracy, exhaustive
precision, recall or a navigation-safety certification. The G-mosaic
correspondence result is reported separately, including the zero matches;
it is not hidden or relabelled as successful detection.
