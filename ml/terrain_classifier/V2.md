# Ground classifier v2: grey input + Perseverance training data (published 2026-11-15)

`ml/exports/terrain_cls.onnx` is now v2. Same ONNX contract (RGB float32 `[1,3,128,128]` 0–1 in,
`logits [1,5]` out), same architecture and size (3.7 MB), one change inside the graph and more data.

## Why

A model study (2026-11-15) found the v1 Curiosity → Perseverance drop was first a colour problem:
**all 200 Curiosity source images are greyscale (R = G = B); none of the 40 Perseverance images
are.** On the retired 197-patch transfer set, grey input alone gained +7.6 points (paired 95% CI
+3.3 to +12.7) and adding 100 Perseverance images reached 71.6%. That set had then been looked at,
so v2 was judged only on a fresh test.

## Protocol (fixed before the fresh test was downloaded)

`v2_protocol.py` was committed before `v2_data.py` fetched the fresh test (see git history).

- **Split:** Perseverance AI4Mars NAV frames grouped in 10-sol blocks; 7 of the 28 labelled blocks
  (sols 0–9, 30–39, 60–79, 90–99, 190–199, 270–279), chosen by hash, are the fresh test. Training
  never sees those blocks. Frames whose label mask is not the image's size (45 of 295) are dropped,
  never resized (`perseverance_v2_manifest.json`, `dropped_size_mismatch`).
- **One candidate, no alternatives:** ITU-R 601 grey conversion in the graph, then v1's frozen
  MobileNetV3-small features and v1's head recipe (Adam 0.01, weight decay 0.001, 200 full-batch
  epochs, inverse class-frequency weights, seed 2026) on 1,136 Curiosity + 901 Perseverance patches.
- **Gates:** fresh Perseverance paired image-bootstrap 95% CI lower bound above 0; balanced
  accuracy improves; at most 2 points lost on each Curiosity expert test (159 and 302 patches).

## Results (ONNX Runtime, `v2_report.json`)

| Test | Patches | v1 | v2 | v2 − v1 (paired 95% CI) |
|---|---:|---:|---:|---|
| Fresh Perseverance (53 frames, 30 with usable patches; 7 sol blocks) | 219 | 90 (41.1%) | **160 (73.1%)** | **+32.0** (+19.4 to +43.7) |
| Curiosity expert v1 (historical) | 159 | 148 (93.1%) | 146 (91.8%) | −1.3 (−5.8 to +2.9) |
| Curiosity expert v2 (fresh 2026-11-14 sample) | 302 | 275 (91.1%) | 284 (94.0%) | +3.0 (−0.3 to +6.4) |

All four gates pass. Balanced accuracy on fresh Perseverance: 0.562 → 0.604.

**What got worse:** sand. Fresh Perseverance sand recall 7/7 → 3/7 (only 7 sand patches);
Curiosity v1-test sand 32/35 → 29/35. On the 302-patch set sand improved, 70/82 → 74/82. Soil and
bedrock recall rose or held on every set (Perseverance soil 49% → 84%, bedrock 19% → 54%).

## Limits

- Perseverance labels are crowd NAV labels; neighbouring sol blocks are nearby places.
- Big rock: zero support in the Curiosity tests, zero in the fresh Perseverance test. No big-rock
  accuracy is claimed (the v3 rock challenge showed v1 finds 15/45).
- Softmax scores are not calibrated; v1's Perseverance confidence was 0.87 at 48% accuracy.
- Not tested on Ingenuity, phone or orbital images. The 200-patch Ingenuity pack is still unlabelled;
  its `baseline_unreviewed_metrics.json` refers to v1.
- The 197-patch v1 transfer set is retired: its 40 frames are now training data where their sols
  fall outside the test blocks.

## Reproduce

```sh
python -m ml.terrain_classifier.dataset ml/data/ai4mars-subset-v1
python -m ml.terrain_classifier.fresh_gale ml/data/ai4mars-subset-v1 ml/data/gale-fresh-v2
python -m ml.terrain_classifier.v2_data ml/data/ai4mars-subset-v1 ml/data/perseverance-v2 [already-fetched dirs]
python -m ml.terrain_classifier.v2_train ml/data/ai4mars-subset-v1 ml/data/perseverance-v2 ml/data/gale-fresh-v2 <v1 onnx> ml/runs/terrain-v2
```

`v2_data.py` reuses frames already fetched into other directories (here the 40 v1 transfer frames
and 100 frames from the model study) and fills the rest by hash; `perseverance_v2_manifest.json`
lists the exact frames and SHA-256 hashes used. Training is deterministic: two runs gave a
byte-identical ONNX. Zenodo serves about one pair every 15 s, so the fetch takes about 45 minutes.
